# GameQuestra X(旧Twitter)アカウント 開設・初期投稿プラン

関連: Issue #74「X自動投稿機能を追加」の**前段**作業。
自動投稿の実装方針は別ドキュメント `docs/x-auto-post-plan.md` を参照。

このドキュメントは、別セッション（別スレッド）でも作業を引き継げるよう、
Xアカウント開設の方針・確定済みの判断・具体的な文案をまとめたもの。
**次回はこのファイルを読めば続きから着手できる。**

---

## Context（背景）

Issue #74 のX自動投稿機能を実装する**前段**として、先にXアカウントを開設し、
手動で初期設定＋初回2〜3回の投稿をしておく。理由は2つ:

1. いきなり記事URLを自動投稿し始めると「正体不明の自動bot」に見え、フォロー・拡散されにくい。
   先に「どんなアカウントか」を伝える土台を作ってから記事流入を始めるのが効果的。
2. 自動投稿機能(generate-posts / post-to-x)は、このアカウントの **tone/bio/世界観** に
   投稿文を合わせる必要がある。先に人格を固めておくと、後の自動投稿テンプレ設計がブレない。

**確定した方針（ユーザー合意済み）:**
- 中の人設定 = **「GameQuestra編集部」として擬人化**。AI運用はプロフィールに軽く明記する程度。
- 文体 = **です・ます調で親しみやすい**（サイト記事のトーン「お届けします」「チェック！」と統一）。
- 初期投稿 = **世界観優先・サイトURLは控えめ**（URLは自己紹介投稿に1回軸足程度、URLだけの投稿はしない）。

**ブランド素材（調査済み・src内の実値）:**
- タグライン: 「AIが届ける、週刊ゲーム情報誌」/「AIが毎週発行するゲーム情報マガジン」
- ロゴ: GAME(黒) + QUESTRA(深紅 #C41E3A)、Cormorant Garamond
- デザイン: Swiss Elegant Editorial、深紅×クリーム、シャープな角(border-radius 0)
- 本番URL: https://game-wire.pages.dev（ドメイン移行は別Issue #212で対応予定。現行ドメインは維持）
- 発行: 毎週土曜 AM6:00 JST、1号=6本立て（新作2/インディー2/特集1/名作深掘り1）
- 対象: Switch / PS4・5 / Xbox / PC(Steam) / iOS・Android の全方位
- 既存号トーン例: 「GameQuestra創刊！…AIがキュレーションしたゲーム情報をお届けします。」

> このプランは**コンテンツ案の提示**であり、コード変更は伴わない。
> アカウント開設・投稿はユーザーが手動で行う。

## 1. アカウント基本設定

### アカウント名（表示名・50字以内）
**案A（推奨）**: `GameQuestra｜週刊ゲーム情報誌`
- ロゴ表記に忠実、何のアカウントか一目で分かる。
- 別案B: `GameQuestra編集部` … 擬人化を前面に出すならこちら。
- 別案C: `GameQuestra｜AIゲームマガジン` … AI色を強める場合。

### ユーザー名（@ハンドル・15字以内・英数_）
優先順に取得を試す（先に空き確認）:
1. `@gamequestra_jp`（推奨。日本向けが明確）
2. `@game_questra_jp`
3. `@gamequestramag`
4. `@gamequestra_mag`

### プロフィール文（bio・160字以内）
**案1（推奨・擬人化＋AI明記＋発行サイクル）**
```
🎮 AIが毎週土曜にお届けする、週刊ゲーム情報誌「GameQuestra」編集部です。
新作・インディー・名作の深掘りまで、注目タイトルをキュレーション。
Switch/PS/Xbox/PC/モバイル対応。 #ゲーム
```
※絵文字・改行込みで160字以内に収まるよう調整（Xはおおむね160字）。

**案2（短く端正・Editorialトーン寄り）**
```
AIが届ける、週刊ゲーム情報誌。
毎週土曜発行。新作からインディー、名作の深掘りまで。
GameQuestra編集部 🖋️
```

### プロフィール周辺
- **アイコン**: 既存ファビコン/ロゴ資産を流用。`public/favicon.svg`・`public/icons/icon-192x192.png`、
  または GAME/WIRE ロゴを正方形に組んだ深紅×クリームのアイコン。角は立てる(Editorial)。
- **ヘッダー画像**: ロゴ＋タグライン「AIが届ける、週刊ゲーム情報誌」を Swiss Editorial 配色で。
- **場所**: 日本 / **Webサイト欄**: https://game-wire.pages.dev （プロフィール欄に置けばURLは投稿で多用しなくてよい）
- **誕生日/カテゴリ**: プロアカウントなら「メディア・ニュース」系カテゴリ。

## 2. 初期投稿案（順に投稿。固定ツイートは①を想定）

### 投稿①：開設の挨拶（→プロフィールに固定推奨）
```
はじめまして、GameQuestra編集部です🎮

私たちは「AIが毎週お届けする、週刊ゲーム情報誌」。
新作からインディー、心に残る名作まで、いま注目のタイトルを
毎週土曜にキュレーションしてお届けします。

これからどうぞよろしくお願いします！

#ゲーム #ゲーム好きと繋がりたい
```
- URLは載せない（プロフィール欄に置いてあるため）。世界観優先。
- これを**固定ツイート**にして、後から来た人が一目で性格を掴めるように。

### 投稿②：何を発信するアカウントか（コンテンツ構成の紹介）
```
GameQuestraでお届けするのは、毎週この4本立て📚

🆕 新作紹介 … もうすぐ/出たばかりの注目作
🎨 インディー … SteamやYouTubeで話題のタイトル
✨ 特集 … 季節やイベントに合わせたテーマ記事
🏆 名作深掘り … 高評価の名作を、評価される理由まで

気になるジャンルはありますか？
```
- 質問で締めてエンゲージ誘発。URLなし。

### 投稿③：なぜ"AI×ゲーム情報誌"なのか（コンセプト＝透明性アピール）
```
「AIが編集する情報誌って、どんな感じ？」

GameQuestraは、Steamの人気度やレビュー、各種データをAIが毎週リサーチし、
注目タイトルを選んで記事に仕立てています🤖🖋️

人の"好き"とAIの"網羅性"のいいとこ取りを目指して。
週末のゲーム選びのお供にどうぞ。
```
- AI運用の透明性を、煽らず前向きに説明。ブランドの核を伝える。

### 投稿④（任意・初号告知へのブリッジ。URLはここで1回だけ軸足）
```
創刊号、公開しています📖
2026年春の注目タイトルを、新作からインディー、名作まで一気にキュレーション。

▶ https://game-wire.pages.dev

毎週土曜あさ6時に新しい号が出ます。よかったら覗いてみてください！
```
- 「世界観優先・URL控えめ」の方針に沿い、URL投稿はこの1本に留める。
- ③まで投稿して反応を見てから④を出す運用でもよい。

## 3. 投稿の順序・タイミング（運用アドバイス）

- 開設当日に **①（固定）→②** を投稿。①を固定ツイートに設定。
- 翌日以降に **③**、さらに数日空けて **④**。1日1本ペースで「中身のあるアカウント」に見せる。
- 初期はURLだらけにしない。フォロワー0の段階ではリンク投稿は伸びにくいため、
  まず人格・世界観・有益さを見せてフォローを獲得 → その後に自動記事投稿(Issue #74)へ移行。
- ハッシュタグは付けすぎない（1〜2個）。`#ゲーム` `#ゲーム好きと繋がりたい` `#インディーゲーム` 等を投稿内容に応じて。

## 4. 自動投稿機能(Issue #74)への引き継ぎポイント

このアカウント設定が固まったら、`docs/x-auto-post-plan.md` の投稿文テンプレ設計に反映する:
- **文体**: です・ます調＋「お届けします」「チェック！」、絵文字は控えめに1〜2個。
- **一人称**: 「GameQuestra編集部」。
- **bio/タグラインの語彙**（「AIが届ける週刊ゲーム情報誌」「キュレーション」）を投稿文でも使い、トンマナ統一。
- **URLの扱い**: 自動投稿では記事URL必須だが、プロフィールに常設してある前提で本文は1リンクに絞る。

## 5. 検証（このプランの「完了」の確認方法）

コード変更がないため、確認は以下:
1. @ハンドルの空き確認（取得可否）。
2. bio が160字以内に収まるか（絵文字・改行込みで実カウント）。
3. 各投稿が280字（日本語は全角140字相当）以内か。
4. アイコン/ヘッダーがブランド配色（深紅 #C41E3A ×クリーム）と整合しているか。
5. プロフィールURL欄に https://game-wire.pages.dev が設定されているか。
